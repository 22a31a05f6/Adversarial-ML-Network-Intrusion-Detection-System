Adversarial Machine Learning in Network Intrusion Detection

This project analyzes the impact of Adversarial Machine Learning (AML) attacks on Network Intrusion Detection Systems (NIDS). It studies poisoning and evasion attacks that manipulate training and testing phases, causing model misclassification. The system classifies adversarial attacks based on knowledge level (white-box, gray-box, black-box) and security violation goals including confidentiality, integrity, and availability.
